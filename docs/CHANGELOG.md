### Important Decisions

- MTPL primary brand color: `#07A25E`
- Phase 1 is enquiry-driven.
- Phase 1 does not use live TBO APIs.
- Phase 1 does not use online payment.
- Phase 1 does not contain the admin panel.
- MongoDB is the application database.
- Production development is prohibited.
- Business content must be data-driven.
- Missing client information must not be invented.
