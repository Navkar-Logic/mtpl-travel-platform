# MTPL Travel Platform — Product Requirements

## 1. Product Vision

Build a premium, trustworthy, responsive travel website for Mishrikotkar Travels Pvt. Ltd. that establishes a strong online presence in Phase 1 and becomes the visual and technical foundation for a full booking platform in Phase 2.

## 2. Phase 1 Goal

Create a production-ready, dynamic, enquiry-driven website with database-backed content.

The site must be designed so Phase 2 can add live booking functionality without rebuilding the public website.

## 3. Phase 1 Included

### Website

- Professional home page
- About Us
- Services
- Flight Booking Services information
- Hotel Booking Services information
- Holiday Packages
- Holiday Package Detail
- Destinations
- Destination Detail
- Sightseeing & Activities
- Visa Assistance
- Offers & Promotions
- Gallery
- Testimonials
- Contact
- Privacy Policy
- Terms & Conditions
- Disclaimer

### Conversion

- Plan Your Trip / Travel Enquiry
- Contact enquiry
- WhatsApp CTA
- Click-to-call
- Google Maps
- Social media links supplied by the client

### Dynamic Content

The following must be data-driven:

- holiday packages
- destinations
- offers
- testimonials
- gallery items
- service content where appropriate
- website settings/contact details

### Technical

- responsive design
- SEO foundation
- accessibility foundation
- form validation
- MongoDB persistence
- error/loading/empty states
- production build
- deployment support
- basic security hardening

## 4. Phase 1 Excluded

- Admin panel
- TBO/Tek Travels flight API
- TBO/Tek Travels hotel API
- live flight results
- live hotel results
- real-time pricing
- online flight booking
- online hotel booking
- payment gateway
- ticket generation
- hotel voucher generation
- PNR retrieval
- customer account/dashboard
- agent portal
- corporate employee portal
- automated cancellation/refund
- automated change/reissue
- mobile application
- advanced CRM
- accounting/ERP
- loyalty system
- advanced coupon engine
- additional supplier integrations

## 5. Phase 2 Direction

Phase 2 will add:

- TBO/Tek Travels Flight API
- TBO/Tek Travels Hotel API
- CCAvenue payment gateway
- flight booking
- hotel booking
- ticket/voucher storage and retrieval
- customer booking retrieval
- booking status handling
- cancellation/refund workflows where supported
- change/reissue workflows where supported
- admin panel
- reporting
- user roles
- operational logs
- notifications

## 6. Core Product Principles

1. Trust over hype.
2. Real content over invented marketing claims.
3. Enquiry-first in Phase 1.
4. Data-driven architecture.
5. Reusable components.
6. Mobile-first responsive behavior.
7. Accessibility is part of implementation, not a later patch.
8. Security-sensitive operations stay server-side.
9. No direct production development.
10. Every completed feature must pass the definition of done.
